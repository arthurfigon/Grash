# Grash

Esqueleto do repositório do jogo Grash — backend em Java 21 (Spring Boot) e frontend em Angular.

Estrutura criada para iniciar o desenvolvimento localmente. Veja o arquivo de arquitetura em `ARCHITECTURE.md`.

Como usar (local):

1. Navegue até a pasta do projeto:

```powershell
cd "c:\Users\arthu\Documents\Projetos\Game\Grash"
```

2. Inicialize o repositório Git e faça o commit inicial (se ainda não foi feito):

```powershell
git init
git add .
git commit -m "chore: initial skeleton"
```

3. Para criar o repositório no GitHub, use o `gh` ou crie via UI e então:

```powershell
git remote add origin <URL_DO_REPOSITORIO>
git branch -M main
git push -u origin main
```
